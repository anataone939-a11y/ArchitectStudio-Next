# ArchitectStudio

Клиентский набор инструментов для ручного строительства и редактирования в Minecraft 1.21.1 (NeoForge 21.1.267).

## Первый этап
- Открытие интерфейса клавишей Right Shift.
- Навигация по разделам редактора.
- Отображение текущих координат игрока и измерения.
- Непаузающий интерфейс, чтобы игровой мир оставался видимым.

Генерация построек и импорт схем не входят в концепцию проекта.

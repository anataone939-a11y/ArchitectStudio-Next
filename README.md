# ArchitectStudio

Клиентский строительный редактор для Minecraft 1.21.1 / NeoForge 21.1.267.

## Текущая версия
`0.1.0` — начальная техническая основа проекта.

## Принципы проекта
- Только ручное редактирование и инструменты строителя.
- Без генерации готовых построек.
- Без зависимости от Litematica.
- Визуальный предпросмотр изменений — один из главных принципов интерфейса.
- Архитектура должна поддерживать расширения и пользовательские инструменты.

## Сборка
Сборка выполняется GitHub Actions. После успешного запуска workflow скачайте артефакт `ArchitectStudio-jar`.

## Среда разработки
- Minecraft: 1.21.1
- NeoForge: 21.1.267
- Java: 21
- ModDevGradle: 2.0.148
- Gradle: 8.14.3
